# Monkey Ball

This repository was to have a place to put the very first game made in TheAtlasEngine in its earlier development of the project.

This project did not have that much features added at the time.


# How to Play?

To play the game:
* Download the zip file.
* Click the TestApp.exe to play the game

# Controls
* Left Arrow to move left (with camera)
* Right Arrow to move right (with camera)
